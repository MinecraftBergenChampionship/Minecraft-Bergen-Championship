# MBC

Source code for MBC Events. Code is dependent on pre-built maps which will remain private.

## Disclaimer
This tournament was initially inspired by, and serves as a partial recreation of, popular Minecraft tournaments such as [MCC](https://twitter.com/mcchampionship_), [BlockWars](https://twitter.com/BlockWarsEvent), and [Pandora's Box](https://twitter.com/PandorasBoxMC). We are not affiliated with these events, nor are we affiliated with Mojang or Minecraft.

**MBC Events are private and no maps will be made available for download.**

## Documentation
Wiki and website will be posted here at a later date. 

## Contribution
MBC is open source as a resource for interested players and as a showcase for developers. Due to the private nature of our event, we are mainly interested in feedback and contribution from internal members, our admins and players. 

If you are a current player, please DM one of the admins for more information on how to contribute. As a general rule of thumb, feel free to fork the repository and offer changes via pull request. Feature requests can be made directly via GitHub issues or by admin DM. Thank you to everyone for their feedback and contribution towards this event!
